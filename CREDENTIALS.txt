HOW TO CHANGE CREDENTIALS:
=================================================================

To change the username/password, edit the file: script.js

Look for the section that says "LOGIN CREDENTIALS - CHANGE THESE AS NEEDED"

Edit the 'users' object. For example:

const users = {
    'admin': { password: 'your_new_password', name: 'Admin User', role: 'admin' },
    'staff': { password: 'your_new_password', name: 'Staff Member', role: 'staff' },
    'newuser': { password: 'newpassword', name: 'New User', role: 'staff' }
};

After editing, save the file and refresh your browser.
